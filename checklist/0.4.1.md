# Checklist v0.4.1

目标：验证 0.4.1 发布前关键能力的人工验收项

## 1. Markdown Skeleton Outline

- [ ] 打开只包含 H1 和 H3 的 Markdown 文件，Skeleton Outline 对应宽度分别为 20px 和 12px
- [ ] 打开包含 H1、H2 和 H4 的 Markdown 文件，Skeleton Outline 对应宽度分别为 20px、14px 和 8px
- [ ] 从 Skeleton Outline 移动到悬停目录时，目录保持显示且标题跳转正常

## 2. Markdown 表格

- [ ] 表格单元格开头的 `- [x]` 和 `- [ ]` 分别显示为已勾选和未勾选 checkbox，在预览中点击切换后同步回写 Markdown 源码
- [ ] 点击 Markdown 表格主复制按钮或 `Copy as Markdown` 时，图片、Task List 标记、转义竖线和 `<u>` 等单元格源码格式保持不变
- [ ] Markdown 复制结果保留右对齐与居中标记、忽略左对齐标记，并使用带空格的标准表格分隔格式
- [ ] Markdown 复制结果中的分隔线与单元格按显示宽度对齐，全角字符按两个字符计算
- [ ] Markdown 复制结果末尾不追加空白行或多余表格行
- [ ] 将包含 checkbox 的表格复制为 ASCII、TSV 或 CSV 时，按当前预览状态输出 `- [x]` 或 `- [ ]`
- [ ] 将 checkbox 复制为 ASCII、TSV 或 CSV 且后面有文字时，任务标记与文字之间只有一个半角空格

## 3. 表格复制交互

- [ ] Markdown 与 CSV/TSV 表格复制菜单均按 Markdown、ASCII、TSV、CSV 的顺序显示
- [ ] `Copy as TSV` 下方显示 `For Excel, Numbers & Sheets`，辅助文字颜色、间距和图标对齐正常
- [ ] 鼠标从 Dropdown Trigger 移向菜单时菜单不会立即消失
- [ ] 点击任意表格复制操作后显示“图标 + Copied”，鼠标离开表格后仍按固定延时消失
- [ ] CSV/TSV 使用 `Cmd/Ctrl+C` 复制多单元格选区后显示“图标 + Copied”

## 4. 预览标题栏

- [ ] Markdown、LaTeX、Mermaid、数据树及 CSV/TSV 预览标题栏均不显示 Feedback 入口
