# Checklist v0.4.0

目标：验证 0.4.0 发布前关键能力的人工验收项

## 1. Markdown Skeleton Outline

- [ ] 打开包含多级标题的 Markdown 文件后，预览右侧显示按标题层级区分长度的 Skeleton Outline
- [ ] 悬停 Skeleton Outline 后显示 TOC，长标题可折行，层级缩进与右侧边缘显示正常
- [ ] 点击 TOC 最后一个标题后，预览立即跳转到对应位置，Webview 底部不出现额外空白

## 2. 滚动锁状态
