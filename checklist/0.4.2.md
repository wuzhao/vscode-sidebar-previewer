# Checklist v0.4.2

目标：验证 0.4.2 发布前关键能力的人工验收项

## 1. Markdown Front Matter

- [ ] Front Matter 标量列表显示为单行标签，内容较长时不折行且可以横向滚动
- [ ] Front Matter 对象、嵌套数组和 JSON 字符串以保留缩进的结构化 JSON 显示
- [ ] Front Matter 标签及结构化内容中的 HTML 字符只显示为文本，不执行为页面元素

## 2. Markdown 样式与 Skeleton Outline

- [ ] Markdown 的 H1 至 H6 标题使用当前 VS Code 主题的链接色
- [ ] 代码块复制按钮的背景、阴影和尺寸与表格复制按钮一致
- [ ] Skeleton Outline 或悬停目录覆盖代码块时，复制按钮及复制成功图标不会遮挡目录

## 3. 复制成功反馈

- [ ] Markdown 代码块复制成功后仅显示 `notebook-state-success` 图标，反馈尺寸与原复制按钮一致
- [ ] Markdown 表格复制成功后仅显示 `notebook-state-success` 图标，反馈宽度覆盖主按钮和下拉区域且整体尺寸不变
- [ ] CSV/TSV 表格复制成功后仅显示 `notebook-state-success` 图标，反馈宽度覆盖主按钮和下拉区域且整体尺寸不变

## 4. Markdown 代码块 Word Wrap

- [ ] Markdown 代码块复制按钮左侧显示同尺寸的纯图标 Word Wrap 按钮，默认使用 `word-wrap` 图标
- [ ] 点击 `word-wrap` 后长代码自动折行，按钮切换为 `symbol-text` 图标及“不折行”提示
- [ ] 点击 `symbol-text` 后恢复不折行，按钮切换回 `word-wrap` 图标及“自动折行”提示
- [ ] LaTeX、Mermaid 和其他非 Markdown 预览中的代码块不显示 Word Wrap 按钮
